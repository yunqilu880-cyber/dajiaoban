# 足元康

智能鞋垫与步态数据分析项目。这个仓库保存品牌网页、数据工作台，以及公开数据资料。

[打开官网](https://yunqilu880-cyber.github.io/dajiaoban/) · [进入数据工作台](https://yunqilu880-cyber.github.io/dajiaoban/workspace.html)

## 数据资料

[下载 Word 修订版：足元康公开数据资料与实验安排](docs/zuyuankang-open-data-and-experiments-20261113.docx)

更新日期：2026年11月13日，共22页。文稿整理了11项真实研究数据资源和6项工程参考项目，包含数据字段、采用顺序、许可条件、受力计算示例、实验步骤和两周安排。

文稿中的受力示例已使用现有两份原始记录复算。分类实验和设备迁移部分属于后续安排，尚无新的模型成绩或临床验证结果。

## 当前网页功能

工作台支持 PhysioNet 公开受力记录回放、同格式 TXT 或 CSV 导入、选段分析、候选周期与受力中心代理量查看，以及分析档案和报告导出。数据处理在浏览器中完成，当前没有账号、云端数据库或真实鞋垫上传服务。

## 文件位置

- `index.html`：官网首页。
- `workspace.html`：数据工作台。
- `research.html`：研究资料与方法说明。
- `scripts/`：数据解析、分析和交互逻辑。
- `data/`：示例记录、格式及数据许可说明。
- `assets/`：网页图片。
- `docs/`：Word 资料文稿。

## 部署

网站由 HTML、CSS 和 JavaScript 构成，无需构建。将仓库根目录作为静态网站目录托管，默认入口为 `index.html`。本地预览需要通过 HTTP 服务访问，工作台使用的模块与数据读取依赖该访问方式。

示例数据和第三方库的许可分别见对应目录。数据来源、使用条件及核验范围详见 Word 文稿。
