02 / THE FORMAT

把字段，
讲清楚。

工作台支持PhysioNet兼容的19列TXT或CSV，文件在当前浏览器中读取。首列必须是秒，其余列必须是牛顿受力，时间严格递增。

列含义单位
1原始时间秒 / s
2–9左脚 L1–L8牛顿 / N
10–17右脚 R1–R8牛顿 / N
18、19左脚、右脚总受力牛顿 / N

本地导入说明

单文件上限10 MB。支持无表头的19列数字；有表头时需使用下方标准名称。读入后检查行数、有限数值、递增时间和总受力一致性。Sole-HARmony原始MAT需要先转换，不属于当前导入格式。

time_s,L1_N,L2_N,L3_N,L4_N,L5_N,L6_N,L7_N,L8_N,R1_N,R2_N,R3_N,R4_N,R5_N,R6_N,R7_N,R8_N,Ltotal_N,Rtotal_N

本地导入由浏览器解析，当前页面未实现上传接口或云端保存。公开样本会随基础页面缓存；导入文件需自行保留。

03 / THE METHOD

方法透明，
结论才有分量。

当前算法版本ZYK-GAIT-0.3。每份片段报告记录来源、SHA-256、范围、单位、数据检查和方法版本，便于重新核查。

01 / 均值与峰值

使用选段原始采样

均值为实际选中采样的算术平均。峰值及其时间直接从双脚总受力相加的记录中查找；点击观察可定位该帧。

02 / 左右分布

按原时间轴积分

采用梯形积分计算各脚受力随时间的累积量，再形成左右占比。该指标只描述这段记录，不设医学正常阈值。

03 / 候选触地

保留待检查的估计

5点移动均值；各脚全记录峰值10%进入、5%退出，同脚事件间隔至少0.25秒。未经过参考标注验证，不等同于真实步数。

04 / 显示与数据

绘图简化，统计完整

曲线按区间极值抽样以保持流畅；统计仍使用全部选段采样。坐标为任意缩放相对点位，不代表毫米或连续压力场。

周期研究与CoP代理：条件随结果保留

同脚相邻候选触地定义估计周期；仅纳入完整落在选段内、通过时长和采样质量筛选的区间。时间轴线性插值至101个相位点，受力保持牛顿，均值与样本标准差使用全部有效周期；n不足2时不输出SD与CV。CoP为8点受力加权相对坐标的代理量，低受力、总量差异与时间缺口不连续连接。当前指标未经参考标注验证，不能换算成毫米轨迹或临床健康结论。
